# Roadmap

## Milestone 1: simple federal return (in progress)

- [x] Tax engine for 2025: W-2, 1099-INT, 1099-DIV, standard deduction, CTC,
      EITC, senior deduction, Additional Medicare Tax, NIIT
- [x] CLI for computing a return from JSON
- [ ] Web app: guided interview, local storage, review screen
- [ ] Fill the official 2025 Form 1040, Schedule 1-A, Schedule 8812, and
      Schedule B PDFs
- [ ] Validate against IRS Assurance Testing System (ATS) scenarios and
      published examples

## Milestone 2: common situations

- [ ] Unemployment (1099-G), Social Security benefits (taxable portion
      worksheet), retirement distributions (1099-R)
- [ ] Schedule 1-A: no tax on tips, overtime, and car loan interest
- [ ] Student loan interest, education credits (Form 8863)
- [ ] Child and dependent care credit (Form 2441)
- [ ] HSA (Form 8889) and IRA deductions
- [ ] QBI deduction for section 199A dividends (Form 8995)

## Milestone 3: investments and self-employment

- [ ] Form 8949 and Schedule D, including 1099-B import
- [ ] Schedule C and Schedule SE
- [ ] Itemized deductions (Schedule A)
- [ ] Premium tax credit (Form 8962)

## Milestone 4: states and filing

- [ ] State returns, starting with states that have simple income taxes
- [ ] 2026 tax year
- [ ] Research the path to IRS e-file authorization
